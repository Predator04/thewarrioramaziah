What changed vs. Direction 1

Corner radius 14-18px → 6px (sharper). Stat panel now uses Anton display type so the numbers read like a fight card. Photo gets an angled clip-path corner cut + faint scanlines + corner brackets — feels like a fight broadcast. The "LIVE SOON" pill became a hot-yellow Anton tag with a pulsing dot. A 3px hot-yellow rule separates the headline from the body (a print-poster move). And a giant low-opacity "WARRIOR" wordmark sits behind the hero as ambient texture. The glow and gradient text from D1 are preserved — you still get the elevated, faith-driven feel.

Quick comparison — what each direction signals

01 · Cinematic Premium

Aspirational, faith-rooted, glow

  • Soft purple gradients + glow auras
  • Gradient highlight on key phrases
  • Glassy floating stat panels
  • Rounded 12-18px corners
  • Best if: photography will be polished/cinematic

02 · Bold Editorial

Fight-poster, loud, magazine

  • Massive Anton display type
  • Hard 2px lines, no rounded corners
  • Scrolling marquee strip + outline type
  • Asymmetric tiles like a print spread
  • Best if: you want unmistakable boxing energy

03 · Modern Minimal

Premium sport, refined, scalable

  • Generous whitespace, soft accents
  • White CTA + small "live" status dot
  • Floating glassy detail cards
  • Closest to today's top athlete sites
  • Best if: you'll add storefront / booking later
